The face

Every page on this site is set in Nether 8, an 8×8 bitmap face drawn in site/font.py and packed into nether.woff (regular, weight 400) and nether-bold.woff (bold, weight 700) without a font library. Six columns of ink (0..5) and one column of blank right bearing make a fixed seven-pixel (896-unit) advance; rows 0..6 sit above the baseline and row 7 below it.

Both weights are drawn by hand: 117 glyphs have a separate 700 drawing and 23 are named in SAME where six columns cannot hold a second pixel without closing a counter, or where box-drawing rules must join across weights. font-synthesis is none, and tests/font/run fails if any glyph in either shipped file is missing from this page.

1. The four sizes

A face drawn on an eight-pixel grid has four sizes at which one pixel of the drawing lands on a whole number of CSS pixels: 8px, 16px, 24px and 32px. Every rule on this site uses one of the four. Each pair below sets the regular (400) above the bold (700) at the same measure.

2. In use and in pairs

A synthetic bold widens every glyph and turns a monospace listing into a ragged one wherever a keyword or a depth annotation is coloured. Each pair of lines below puts 400 directly above 700 so any drift in advance or closed counter shows immediately.

In running prose at 16px on 22px leading, bold weight, underlined emphasis, inline code(0x1f) and the nine stratum stains (@0 @1 @2 @3 @4 @5 @6 @7 @8) share the same seven-pixel advance.
